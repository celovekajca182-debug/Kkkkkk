# LAST ZONE 3D — Battle Royale prototype

Мобильный браузерный 3D-прототип с видом от третьего лица.

## Запуск
Откройте опубликованную GitHub Pages-версию или локально запустите через любой простой HTTP-сервер. Three.js загружается с jsDelivr CDN, поэтому для запуска нужен интернет.

Чтобы включить GitHub Pages: Settings → Pages → Deploy from a branch → Branch: main → Folder: / (root) → Save.

## Управление
- Телефон: горизонтальная ориентация; левый джойстик — движение; правая кнопка — стрельба; проводите пальцем по центральной области для поворота камеры.
- ПК: WASD — движение, Space — огонь.

## Реализовано в прототипе
- 3D-сцена на Three.js, камера от третьего лица, освещение, туман и тени.
- Игровая площадка, деревья, камни и простые здания.
- Игрок и 24 3D-бота с именами, перемещением и перестрелками.
- Пули, здоровье, киллы, килл-фид и сужающаяся зона.
- Адаптивный полноэкранный интерфейс без фиксированного 16:9; запрашивается альбомная ориентация.

## Пока не реализовано
Онлайн-мультиплеер, полноценные анимации и модели персонажей, транспорт, подбор лута, инвентарь, парашют и серверная логика. Это ранний игровой прототип, не готовый аналог PUBG.
