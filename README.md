# SWIN AI
Собственная экспериментальная языковая модель и Android-клиент. Проект не использует платные AI API и не проксирует запросы к ChatGPT/DeepSeek.

## Состояние
Это ранний исследовательский прототип: символьная RNN с обучаемыми весами. Она учится предсказывать следующий символ, а не обладает интеллектом уровня большой языковой модели. Не называем её готовой умной нейросетью.

## Обучение
В каталоге server:
```bash
pip install -r requirements.txt
python train.py --data data/train.txt --epochs 30
```
Сохрани полученный `model.npz` в `server/`. На Android это обучать неэффективно; телефон можно использовать для управления GitHub и Render. Обучение на Render Free может не поместиться по памяти/времени. Для серьёзного обучения нужны GPU-ресурсы.

## Render
Root Directory: `server`
Build: `pip install -r requirements.txt`
Start: `uvicorn app:app --host 0.0.0.0 --port $PORT`

Добавь `model.npz` в серверное окружение/репозиторий только если размер позволяет. Не клади секреты в Git.

## Android
В `android/` — Kotlin-клиент. Замени URL сервера в MainActivity.kt, затем запусти GitHub Actions workflow для сборки APK.

## План качества
1. Собрать лицензированный и проверенный русскоязычный корпус.
2. Перейти от символьной RNN к токенизатору и Transformer.
3. Добавить тесты, оценку качества и фильтрацию обучающих данных.
4. Дообучать модель на инструкциях и диалогах.
5. Отдельно реализовать память диалога и поиск по собственной базе знаний.

SWIN AI может помогать с программированием, моддингом и анализом собственных проектов. Для читов — поддержка только в собственных играх, офлайн/одиночных режимах и разрешённом моддинге; не будем добавлять обход античита, кражу аккаунтов или вмешательство в чужие онлайн-матчи.
