# LAST ZONE 3D — Android-ready Battle Royale prototype

Устанавливаемая PWA-игра для Android с 3D-видом от третьего лица.

## Опубликовать игру (один раз)
1. Откройте Settings репозитория на GitHub.
2. Перейдите в Pages.
3. В разделе Build and deployment выберите Deploy from a branch.
4. Выберите ветку main и папку /(root), затем Save.
5. Дождитесь публикации. Адрес будет: https://celovekajca182-debug.github.io/Kkkkkk/

## Установить на Android
1. Откройте опубликованный адрес в Chrome на Android.
2. Дождитесь полной загрузки игры и нажмите меню Chrome (⋮).
3. Выберите «Установить приложение» или «Добавить на главный экран».
4. Запустите LAST ZONE с появившейся иконки и поверните телефон горизонтально.

Для первой загрузки нужен интернет. Service worker сохраняет оболочку игры и модуль Three.js для последующих запусков; полноценная автономная игра не гарантируется, если CDN не был закэширован или браузер очистил хранилище.

## Управление
- Android: горизонтальная ориентация; левый джойстик — движение; правая кнопка — огонь; проводите пальцем по центральной области для поворота камеры.
- ПК: WASD — движение, Space — огонь.

## Реализовано в прототипе
- 3D-сцена Three.js, камера от третьего лица, освещение и туман.
- Карта, деревья, камни и простые здания.
- Игрок и 24 бота с именами, перемещением и перестрелками.
- Пули, здоровье, убийства, kill feed и сужающаяся зона.
- Настройки рендеринга для Android и автоматическое снижение разрешения при просадке FPS.
- PWA-манифест, иконка и service worker для установки на главный экран.

## Пока не реализовано
Онлайн-мультиплеер, полноценные модели и анимации, транспорт, лут, инвентарь и парашют. Это ранний игровой прототип, не готовый аналог PUBG.
