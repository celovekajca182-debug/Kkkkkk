# SWIN AI

Собственная экспериментальная языковая модель и Android-клиент. SWIN не обращается к ChatGPT, DeepSeek или платным AI API. Веса учебной модели создаются своим циклом обучения с нуля.

## Архитектура 0.3

- **ByteTokenizer** — переводит текст в UTF-8 байты (256 возможных токенов), поэтому русский язык поддерживается без скачиваемого словаря.
- **SWINTransformer** — небольшой decoder-only Transformer с causal self-attention, позиционными embedding, feed-forward блоками и собственной матрицей весов.
- **TinyCharRNN** — прежняя учебная RNN сохранена как резервный вариант.
- **KnowledgeBase** — поиск по проверенным локальным материалам. Для известных технических вопросов поиск имеет приоритет над генерацией.
- **Conversation memory** — сервер хранит до 6 пар сообщений на session_id и до 256 активных сессий. Память находится в RAM процесса и очищается при перезапуске сервера.
- **Android** — хранит уникальный session_id на телефоне, передаёт его API и продолжает поддерживать ограниченные офлайн-ответы.

## Установка зависимостей

Базовый API:
```bash
pip install -r server/requirements.txt
```

Для обучения или запуска Transformer добавь CPU-сборку PyTorch:
```bash
pip install -r server/requirements-transformer.txt --extra-index-url https://download.pytorch.org/whl/cpu
```

## Обучение SWIN Transformer с нуля

Из каталога `server`:
```bash
python train_transformer.py --epochs 15 --output models/swin-transformer.pt
```

Скрипт собирает текст из `data/train.txt`, `data/knowledge.json` и дополнительных диалогов `data/dialogue.jsonl`, создаёт новую случайно инициализированную модель, обучает её предсказывать следующий UTF-8 байт, измеряет train/validation loss и сохраняет лучший checkpoint.

Параметры по умолчанию: контекст 128 байт, d_model 96, 4 attention heads, 2 Transformer-блока. Это небольшой учебный эксперимент, не конкурент большой языковой модели. Текущий набор диалогов годится для проверки архитектуры и pipeline, но недостаточен для широких и надёжных знаний. Увеличение эпох не заменяет качественные данные.

GitHub Actions автоматически запускает workflow **Train SWIN Transformer** после изменений обучающего кода или данных. Результат появляется в Artifacts как `swin-ai-transformer-weights`. Это артефакт сборки; для API положи файл в `server/models/swin-transformer.pt` или укажи переменную `SWIN_TRANSFORMER_PATH`.

## Запуск API

Из каталога `server`:
```bash
uvicorn app:app --host 0.0.0.0 --port 8000
```

Основные маршруты:
- `GET /` и `GET /health` — статус и сведения о загруженных весах.
- `POST /chat` — JSON с `message` и необязательным `session_id`.
- `POST /memory/clear` — сброс истории сессии.

В Render blueprint установлен отдельный CPU PyTorch. После деплоя checkpoint всё равно надо добавить в доступный серверу файл/volume и задать `SWIN_TRANSFORMER_PATH`, если путь отличается от стандартного.

## Android APK

Workflow **Build SWIN AI APK** собирает debug APK. Открой GitHub → Actions → успешный запуск → Artifacts и скачай `swin-ai-debug-apk`. В поле сверху приложения укажи HTTPS-адрес своего API. Без сервера работает встроенный офлайн-справочник, но он отвечает только на знакомые темы.

## Следующие шаги качества

1. Расширить проверенный русскоязычный корпус и добавить отдельный validation/evaluation набор.
2. Добавить BPE/SentencePiece токенизатор, чтобы русский текст кодировался эффективнее, чем отдельными байтами.
3. Добавить диалоговое instruction tuning, регулярную оценку фактов и кода.
4. Перенести обучение с CPU на GPU, когда модель и корпус существенно вырастут.

SWIN AI может помогать с программированием, отладкой, своими играми, офлайн-моддингом и разрешёнными модификациями. Для собственной игры поддерживаются debug-инструменты, тестовые режимы и офлайн-трейнеры; обход античита и вмешательство в чужие онлайн-матчи не входят в проект.
