# SWIN AI

Собственная экспериментальная языковая модель и Android-клиент. Проект не вызывает платные AI API и не отправляет запросы к ChatGPT, DeepSeek или другим внешним AI-моделям.

## Текущая архитектура

- **Android OfflineKnowledge** — встроенные в APK ответы по базовым вопросам Godot, Python, Android/Gradle, нейросетям и собственным офлайн-модам. Работает без интернета, но отвечает только по добавленным темам.
- **Локальная база знаний сервера** — поиск по подготовленным материалам в `server/data/knowledge.json`.
- **TinyCharRNN** — собственная учебная символьная рекуррентная сеть на NumPy. Она обучает свои веса предсказывать следующий символ. Это пока не Transformer и не модель уровня больших чат-ботов.
- **FastAPI** — серверные маршруты /chat, /health и /.
- **Android-клиент** — чат с полем для HTTPS-адреса собственного сервера. Адрес сохраняется на телефоне; при отсутствии сети он пробует встроенную офлайн-базу.

## Обучение своих весов

Из каталога `server`:
```bash
pip install -r requirements.txt
python train.py --data data/train.txt --epochs 30 --output model.npz
```

Обучение создаёт `model.npz`. Для запуска API положи файл в каталог `server` либо задай переменную окружения `SWIN_MODEL_PATH`.

Последний автоматический пробный запуск создал собственные веса модели (96 скрытых нейронов, алфавит 62 символа). Текущий корпус содержит всего 709 символов — этого достаточно, чтобы проверить обучение и сохранение параметров, но совершенно недостаточно для умного универсального диалога. Снижение loss на этих данных не является показателем качества на новых вопросах.

## Запуск API

Из каталога `server`:
```bash
uvicorn app:app --host 0.0.0.0 --port 8000
```

Локальная серверная база знаний отвечает на совпадающие вопросы даже без `model.npz`. Если совпадения нет и веса ещё не загружены, API возвращает понятный статус, а не выдумывает факт.

## Android APK

Workflow **Build SWIN AI APK** собирает debug APK в GitHub Actions. APK можно забрать из раздела Actions → нужный запуск → Artifacts. В поле сверху приложения вставляется HTTPS-адрес собственного API; без него работает встроенная ограниченная офлайн-база.

## Как расширять

1. Добавлять проверенные русскоязычные инструкции в `server/data/knowledge.json` и Android OfflineKnowledge.
2. Собирать собственный лицензированный обучающий корпус; не раздувать его механическими повторами.
3. Добавить токенизатор, затем перейти на Transformer с обучением весов на GPU.
4. Добавить валидационные метрики, журнал обучения, диалоговую память и поиск по файлам проекта.

SWIN AI можно развивать как помощника по программированию, отладке, собственным играм, офлайн-моддингу и разрешённым модификациям. Инструменты должны работать в собственных проектах, одиночных режимах или с разрешения владельца; обход античита и вмешательство в чужие онлайн-матчи не входят в проект.
