# SWIN AI

Собственная экспериментальная языковая модель и Android-клиент. Проект не вызывает платные AI API и не отправляет запросы к ChatGPT, DeepSeek или другим внешним AI-моделям.

## Текущая архитектура

- **Локальная база знаний** — офлайн-поиск по подготовленным материалам. Даёт структурированные ответы на темы, которые уже добавлены в базу.
- **TinyCharRNN** — собственная учебная символьная рекуррентная сеть на NumPy. Она обучает свои веса предсказывать следующий символ. Это пока не Transformer и не модель уровня больших чат-ботов.
- **FastAPI** — серверные маршруты /chat, /health и /.
- **Android-клиент** — чат с полем для HTTPS-адреса собственного сервера. Адрес сохраняется на телефоне.

## Обучение своих весов

Из каталога `server`:
```bash
pip install -r requirements.txt
python train.py --data data/train.txt --epochs 30 --output model.npz
```

Обучение создаёт `model.npz`. Для запуска API положи файл в каталог `server` либо задай переменную окружения `SWIN_MODEL_PATH`.

Важно: текущий корпус демонстрационный и слишком маленький для умного диалога. Он нужен для проверки конвейера обучения. Для роста качества нужны тысячи или миллионы качественных токенов, лицензированные данные, отдельная оценка и переход на Transformer. GitHub Actions запускает CPU-обучение малого прототипа, а не серьёзное обучение большой модели.

## Запуск API

Из каталога `server`:
```bash
uvicorn app:app --host 0.0.0.0 --port 8000
```

Локальная база знаний отвечает на совпадающие вопросы даже без `model.npz`. Если совпадения нет и веса ещё не загружены, API возвращает понятный статус, а не выдумывает факт.

## Android APK

Workflow **Build SWIN AI APK** собирает debug APK в GitHub Actions. APK можно забрать из раздела Actions → нужный запуск → Artifacts. После публикации API вставь HTTPS-адрес сервера в поле сверху в приложении.

## Как расширять

1. Добавлять проверенные русскоязычные инструкции в `server/data/knowledge.json`.
2. Собирать собственный лицензированный обучающий корпус; не раздувать его механическими повторами.
3. Добавить токенизатор, затем перейти на Transformer с обучением весов на GPU.
4. Добавить тесты, измерения качества, журнал обучения, диалоговую память и поиск по файлам проекта.

SWIN AI можно развивать как помощника по программированию, отладке, собственным играм, офлайн-моддингу и разрешённым модификациям. Инструменты должны работать в собственных проектах, одиночных режимах или с разрешения владельца; обход античита и вмешательство в чужие онлайн-матчи не входят в проект.
