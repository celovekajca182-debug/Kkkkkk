# LAST ZONE — Battle Royale demo

Мобильная браузерная демо-игра в горизонтальной ориентации.

## Запуск
Откройте `index.html` в браузере. Для установки как веб-приложения и офлайн-кэша опубликуйте репозиторий через GitHub Pages (Settings → Pages → Deploy from a branch → main → /root).

## Управление
- Левый экранный джойстик — движение.
- Правая кнопка «ОГОНЬ» — стрельба по ближайшему противнику.
- На компьютере: WASD и Space.

## Состав демо
- Большая процедурная игровая зона с препятствиями.
- 24 бота с отдельными именами, перемещением и перестрелками друг с другом.
- Сужающаяся безопасная зона, здоровье, счётчик выживших и килл-фид.
- Адаптивный полноэкранный canvas без фиксированного соотношения сторон; манифест запрашивает landscape.

Это ранний прототип, а не готовая онлайн-игра уровня PUBG. Сетевой мультиплеер, полноценная 3D-графика, транспорт и инвентарь пока не реализованы.
