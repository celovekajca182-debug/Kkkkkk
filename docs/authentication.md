# Регистрация и вход SWIN AI

## Функции

- Регистрация по адресу электронной почты и паролю.
- Вход и выход из аккаунта.
- Проверка текущей сессии через \`GET /auth/me\`.
- Случайный bearer-токен со сроком действия 30 дней.
- Отзыв токена при выходе.
- Память диалога разделена по ID пользователя и ID сессии приложения.

## Безопасность

Пароли хешируются Argon2id через \`pwdlib[argon2]\`. Исходный пароль никогда не записывается в SQLite. Сервер хранит только Argon2id-хеш. Токены генерируются криптографически стойким генератором случайных чисел; в SQLite сохраняется только SHA-256 digest токена, не сам bearer-токен.

Android-клиент шифрует полученный токен алгоритмом AES-GCM с ключом, созданным Android Keystore. Файл с токеном исключён из резервного копирования приложения. Пароль не сохраняется на устройстве после ответа сервера.

Ограничение попыток регистрации и входа: 5 регистраций или 10 попыток входа с одного IP за 5 минут в пределах одного процесса сервера. Для нескольких экземпляров сервера нужен общий rate limiter на уровне reverse proxy или общей базы данных.

Почта используется как уникальный логин. Отправка письма с кодом подтверждения и восстановление пароля пока не реализованы — для них нужно отдельно подключить SMTP-провайдера и механизм одноразовых кодов. Не выдавай адрес за подтверждённый.

## API

### Регистрация

\`POST /auth/register\`

\`\`\`json
{"email":"user@example.com","password":"minimum-12-chars"}
\`\`\`

Возвращает bearer token и объект пользователя. Минимальная длина пароля — 12 символов; максимальная — 128.

### Вход

\`POST /auth/login\`

\`\`\`json
{"email":"user@example.com","password":"minimum-12-chars"}
\`\`\`

### Текущий пользователь

\`GET /auth/me\`

Требует заголовок \`Authorization: Bearer <token>\`.

### Выход

\`POST /auth/logout\`

Требует тот же bearer token. Удаляет соответствующий токен из SQLite.

### Чат

\`POST /chat\`

Требует bearer token и тело:

\`\`\`json
{"message":"Привет","session_id":"client-session-uuid"}
\`\`\`

История сохраняется только в оперативной памяти процесса и ограничена последними 6 парами сообщений на пользователя и сессию. Она очищается после перезапуска сервера.

## Развёртывание

По умолчанию SQLite-файл создаётся по пути \`server/data/swin.sqlite3\` при запуске API из каталога \`server\`.

Задай \`SWIN_DATABASE_PATH\` на постоянный том, если хостинг предоставляет persistent disk. Не полагайся на локальный диск бесплатного/эфемерного контейнера: при пересоздании такого контейнера база и аккаунты могут исчезнуть. Резервные копии базы должны храниться отдельно и быть защищены.

Мобильный клиент требует HTTPS-адрес сервера. Не используй HTTP в открытых сетях.
